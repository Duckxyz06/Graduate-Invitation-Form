Bước 1 — Tạo Google Sheet

Vào sheets.google.com → Tạo bảng mới. Hàng đầu tiên nhập 4 cột: Timestamp Tên Tham dự Thiệp

Bước 2 — Tạo Apps Script

Trong Sheet → Extensions → Apps Script → xoá code cũ → dán:

function doPost(e) { var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet(); var data = JSON.parse(e.postData.contents); sheet.appendRow([ new Date().toLocaleString('vi-VN'), data.ten, data.thamDu, data.thiep ]); return ContentService .createTextOutput(JSON.stringify({ok:true})) .setMimeType(ContentService.MimeType.JSON); }
Bước 3 — Deploy

Deploy → New deployment → Web app
Execute as: Me  ·  Who has access: Anyone
→ Deploy → Authorize → Copy URL → dán vào ô Script URL bên trên.

Bước 4 — Upload nhạc lên GitHub

Kéo file .mp3 vào repo GitHub → Commit → Mở file → bấm Raw → copy URL → dán vào ô Nhạc nền bên trên.
